> 版本:v1.0(2026-11-01)|上游:《包厢房态模块-构建指导》(房账/状态机)·《需求全集 V3.0》第六章(计费)

## 一、操作总览(谁在哪端做什么)

| 操作 | 艺人端小程序 | 管理端 Web | 说明 |

## 二、艺人自点单(核心流程)

### 2.1 流程时序

```
艺人(房内) → 小程序「我的包厢」→ [点单]
  → 商品目录(仅"销售商品=是"项,继承商品档案;按类型分组)
  → 购物车(数量步进) → 提交
    ├─ 前置校验(单源):
    │    ① session 存在且 OPEN(否则 40908 ROOM_NOT_OPEN)
    │    ② 本人 ∈ session.artistIds(否则 40909 NOT_IN_ROOM)
    │    ③ 限额:单笔 ≤ 单笔限额 且 当日累计 ≤ 日累计限额(否则 40910,可走管理员审批放行)
    │    ④ 商品在售
  → self_order(status=PLACED) → 吧台/厨房履约 → DELIVERED
  → session.order_total 累加 → 房态看板卡片金额实时刷新
关房时:点单明细随结算单一并结算(现金/台费抵扣/混合)
```

### 2.2 数据模型(增量 DDL)

```sql
-- 艺人自点单(房账子单;只增,履约为状态更新)
CREATE TABLE self_order (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  store_id      BIGINT UNSIGNED NOT NULL,
  business_date DATE NOT NULL,
  session_id    BIGINT UNSIGNED NOT NULL COMMENT '房账id',
  room_id       BIGINT UNSIGNED NOT NULL,
  artist_id     BIGINT UNSIGNED NOT NULL COMMENT '点单人',
  items         JSON NOT NULL COMMENT '[{goodsId,name,qty,unitPrice}]快照',
  total_amount  DECIMAL(10,2) NOT NULL,
  status        VARCHAR(16) NOT NULL DEFAULT 'PLACED' COMMENT 'PLACED/DELIVERED/CANCELLED',
  placed_at     DATETIME DEFAULT CURRENT_TIMESTAMP,
  delivered_at  DATETIME NULL,
  remark        VARCHAR(255) NULL,
  KEY idx_session (session_id),
  KEY idx_store_date (store_id, business_date),
  KEY idx_artist (artist_id, business_date)
) COMMENT '艺人自点单(只增)';

-- 商品目录简化档(独立系统起步;II 期对接主系统商品管理同步)
CREATE TABLE goods (
  id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  store_id    BIGINT UNSIGNED NOT NULL,
  name        VARCHAR(64) NOT NULL,
  category    VARCHAR(32) NULL COMMENT '啤酒/软饮/小吃/果盘…',
  unit        VARCHAR(16) NULL,
  sale_price  DECIMAL(10,2) NOT NULL,
  on_sale     TINYINT(1) NOT NULL DEFAULT 1,
  sort        INT DEFAULT 0,
  deleted_at  DATETIME NULL,
  UNIQUE KEY uk_store_name (store_id, name)
) COMMENT '商品目录(自点单)';
```

### 2.3 限额与风控(配置矩阵增补)

| 配置(env/门店级) | 默认 | 说明 |
|---|---|---|
| SELF_ORDER_PER_TXN_LIMIT | 500 元 | 单笔限额;超限 40910(管理员可在审批中心放行) |
| SELF_ORDER_DAILY_LIMIT | 2000 元 | 艺人当日累计(ΣPLACED+DELIVERED) |
| SELF_ORDER_REQUIRE_CHECKIN | true | 未报备签到禁止点单(联动考勤) |
| SELF_ORDER_DELIVERERS | 吧台/果盘组 | 履约提醒接收方(订阅消息/看板响铃) |

### 2.5 页面

**艺人端小程序**
- 「我的包厢」:当前房卡(房名/时长实时跳动/房内同伴/累计消费)→ 按钮:点单 · 加入/离开 · 关房结算(发起人可见)
- 「点单」:分类 Tab(啤酒/软饮/小吃/果盘…)→ 商品卡(图/名/价/步进)→ 底部购物车(合计/提交)→ 下单成功页(单号/预计送达)
- 「我的订单」:本人自点单列表(状态:已下单/已送达/已取消;金额)
- 「开房」:选房型(带时薪)→ 选空闲房(40907 占用禁选)→ 勾选同房艺人 → 确认(展示计费规则提示)

**管理端 Web**
- 房详情抽屉增「点单记录」Tab(按 session 列自点单,可代履约/代取消/代点登记)
- 商品管理页(目录 CRUD,继承实测商品管理字段简化版:名称/类型/单位/售价/在售)

## 三、关房结算与台费联动(与房态模块衔接)

1. 关房结算单 = **时间费**(`calcBillHours × unit_price`,开房快照)+ **Σ self_order**(PLACED+DELIVERED,关房时未送达单提示「含未送达单,是否一并结算」)
2. 支付:`CASH` 现金全额 / `FEE_DEDUCT` 台费抵扣(按在场艺人各自余额分配,校验 `sumFeeBalance`,不足不可超扣——`ALLOW_NEGATIVE_BALANCE=true` 时可负并红显)/ `MIXED` 混合
3. 台费抵扣落 `stage_fee_txn(ROOM_SETTLE, −amount, ref=session_id)`,**流水不可变**;艺人端「我的流水」即时可见
4. 结算完成 → self_order 全部终态封单 → session CLOSED → 房进 CLEANING

## 四、验收要点

| # | 用例 | 预期 |
|---|---|---|
| O-01★ | 艺人自点单全链 | 房内艺人点单→PLACED→DELIVERED→order_total 累加→关房结算含该单 |
| O-02 | 非房内艺人点单 | 40909 拒绝 |

| O-09 | 取消单 | 仅 PLACED 可取消;关房后禁止取消 |
