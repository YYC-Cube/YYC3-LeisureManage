## 一、双机拓扑（2026-11-02 现状）

| 节点 | 角色 | 地址 | 说明 |
| --- | --- | --- | --- |
| **yyc3-33**（阿里云 ECS） | 边缘网关 | 公网 `39.97.53.176` · Tailscale `10.200.0.x(wg0)` | Traefik v3(TLS 终止)→ 边缘 nginx `yyc3-leisure-edge`(8070) → 隧道 |
| **yyc3-45**（NAS F4-423） | 应用备节点 + PG15 **备库(只读)** | 内网 `192.168.3.45` · Tailscale `100.65.172.88` | Docker 层 `/Volume3/docker/`：`yyc3-leisure-api:1.0.0-rc.1`(3001,当前**回退位**) + `yyc3-leisure-frpc`(→ECS 8801) |
| **Mac（本机，yyc3）** | **PG15 主库 + 生产 API 主节点** | 内网 `192.168.1.9`(漂移) · **Tailscale `100.87.159.21`(稳定,连库一律走此)** | Homebrew postgresql@15 :5433；launchd `com.yyc3.leisure-api-prod`(:3002) + `com.yyc3.leisure-frp`(SSH 隧道 8802) |

> **性能结论（实测）**：NAS↔Mac 的 Tailscale 走 DERP 中继（relay "nue"），API(NAS)↔DB(Mac) 每查 200ms+ 绕德国——已把生产 API 迁至 Mac 与主库同机，DB 零网络跳数（auth/me <1.2ms，DB 重端点公网 115-195ms）。

## 三、请求全链路（正向）

```
浏览器/PWA
  → ECS Traefik(:443, TLS 终止, dynamic.yml 路由 lm.*)
    → 边缘 nginx yyc3-leisure-edge(127.0.0.1:8070)
        ├ /            → 静态 web/(管理端 SPA, hash 路由)
        ├ /m/          → 静态 h5/(艺人端, API_BASE 内联 lm.0379.pro)
        └ /api/v1/     → host.docker.internal:8802
            → SSH 反向隧道(Mac launchd com.yyc3.leisure-frp)
              → Mac 127.0.0.1:3002 生产 API(launchd com.yyc3.leisure-api-prod)
                → localhost:5433 PG15 主库
```

**回退链路**：`8802` 不可用时切回 NAS 链路 —— 边缘 upstream 改 `host.docker.internal:8801`（NAS frpc → NAS API :3001）。

| frp 隧道(NAS) | NAS docker | ECS 8801→NAS 3001 | yyc3-leisure-frpc |

## 五、数据流与存储

- **业务库**：`leisure`(PG15 主库,38 表)——账号最小化：API 走 `leisure_app`(流水/审计/台票三表 REVOKE UPDATE·DELETE),迁移走所有者 `leisure`
- **双轨对账**：日切 job 每晚自动快照自算四指标 → 次日人工录对侧 → 14 天门禁
- **审计**：全动作 audit_log（DB 层对 leisure_app REVOKE 删除）
- **密钥**：真值只存 `~/.yyc3-keybackup/leisure-prod.env`(600)，生成器 `scripts/gen-prod-secrets.sh`
