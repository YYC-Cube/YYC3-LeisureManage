## A. 交接班对账(008 #11;本批新增接班码)

| # | 操作 | 预期 |
|---|---|---|
| A1 | 登录管理端 → 侧栏「台费资金」域 → 「交接班对账」 | 页面加载;列表显示历史交接单(含本期前的) |
| A2 | 点「+ 生成交接班单」→ 填班次名(如「验收-晚班」)→ 生成 | toast 显示**6 位接班码**;列表新行状态 OPEN,接班码列显示同码 |
| A3 | 核对四合计:与「台费充值记录/扣费记录/关房结算流水/点单」当日合计一致 | 快照金额与明细页汇总一致;未结订单数正确 |
| A4 | 点「接班确认」→ 先输错码(000000 等)提交 | 按钮在非 6 位时禁用;错码提交报「接班码不匹配」 |
| A5 | 输入正确 6 位码 → 确认 | 状态变 CONFIRMED;接班码列变「—」 |
| A6 | 点「打印」→ 新页显示对账单 → 「打印/存 PDF」 | 版式含 YYC³ logo、四合计、签字栏;OPEN 单另显示接班码大字;PDF 保存成功 |
| A7 | 重复对 A2 确认过的单执行确认 | 单已 CONFIRMED,无确认按钮(状态保护) |

## B. 财务分账(008 #12;本批新增预算对比/结算导出/资金域入口)

| # | 操作 | 预期 |
|---|---|---|
| B1 | 侧栏「台费资金」域(不再是「设置」域)→ 「财务分账」;移动端 /m/workbench → 底部「资金」分组 | 桌面+移动均能进入;移动宫格含「财务分账/交接班对账」图标 |
| B2 | 页首「三向对账」卡 | 显示 平衡/差异 徽标+计提净额/已入结算/各状态合计(生产新表为空时应显示平衡) |
| B3 | 「+ 新建方案」→ 填名称/类目=上钟业绩/比例 20/**预算金额(如 5000)** → 创建 | 方案卡显示预算进度条(0%,达成 0%) |
| B4 | 方案卡「计提并激活」→ 按当日上钟数据计提 | toast 显示条数与合计;卡面实际金额更新,预算达成率=实际/预算 |
| B5 | 人工将某销售经理当日业绩乘 20% 心算核对 | 计提额=基数×比例;多次点击「按今日计提」不重复计提(幂等) |
| B6 | 「手动计提」→ 对象=销售经理,金额填负数(罚扣)≥阈值 | ≥阈值时进入「待复核」卡(状态 PENDING) |
| B7 | 待复核卡 → 通过/驳回(另一操作人复核语义:当前账号即制单人时后端应拒绝) | 复核人≠制单人约束生效;通过后条目 CONFIRMED |
| B8 | 「生成结算单」→ 选对象/周期(本月)/支付方式 CASH → 生成 | 结算单列表新行:金额=该对象周期内 ACCRUED 合计,状态 CONFIRMED |
| B9 | 结算行「导出」→ 打开 xlsx | Excel/WPS 可开:头 3 行单据信息+条目明细表(营业日/方案/类目/基数/计提额/状态) |
| B10 | 「支付确认」→ 填凭证号 → 确认 | 状态 PAID;若支付方式=OFFSET,台费流水出现对应 MANUAL_DEDUCT 冲抵记录 |
| B11 | 支付后回看「三向对账」卡 | CONFIRMED+PAID=结算单合计,徽标「平衡」 |
| B12 | 报表中心 → 「分账计提明细」「分账结算汇总」→ 三格式导出 | json/csv/xlsx 均可下载,xlsx 直开 |
