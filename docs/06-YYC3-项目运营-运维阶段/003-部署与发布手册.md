## 一、首次部署（已完成 2026-11-02；重放用）

1. **数据库**（Mac 主库机）：
   ```bash
   bash services/leisure-api/scripts/pg-prod-bootstrap.sh --host 127.0.0.1 --port 5433 --superuser yanyu
   DATABASE_URL="$DATABASE_URL_OWNER" pnpm --dir services/leisure-api exec prisma migrate deploy
   psql "$OWNER_URL" -d leisure -f services/leisure-api/scripts/apply-pg-grants.sql
   DATABASE_URL="$DATABASE_URL_OWNER" NODE_ENV=prod pnpm --dir services/leisure-api exec prisma db seed
   ```
2. **Mac 生产 API**：`launchctl load ~/Library/LaunchAgents/com.yyc3.leisure-api-prod.plist`（监听 3002）
3. **Mac frp 隧道**：`launchctl load ~/Library/LaunchAgents/com.yyc3.leisure-frp.plist`（8802→3002）
4. **边缘 nginx**（ECS）：`/root/yyc3-leisure-edge/` compose up；`/api/v1/` upstream=8802
5. **NAS API 备实例**（可选回退位）：`/Volume3/docker/yyc3-leisure-api/` compose up
6. 静态发布：`web/`（管理端 dist）+ `h5/`（销售端 dist，`TARO_APP_API_BASE=https://lm.0379.pro/api/v1`）

## 二、版本发布（标准流）

```bash
# 1) 本机构建（Web）
cd apps/app-leisure-web && pnpm type-check && pnpm build
rsync -az --delete dist/ yyc3-33:/root/yyc3-leisure-edge/web/

# 2) 销售端 H5（API_BASE 内联）
cd apps/app-mp-artist && TARO_APP_API_BASE='https://lm.0379.pro/api/v1' pnpm build:h5
rsync -az --delete dist/ yyc3-33:/root/yyc3-leisure-edge/h5/

# 3) 后端（Mac 主实例）
cd services/leisure-api && pnpm build   # dist 更新 → launchd 自动拉起新进程? 否：launchd 不监听文件
kill $(launchctl list | grep leisure-api-prod | awk '{print $1}')   # KeepAlive 自动重启加载新 dist
```

- 发布窗口内静态即 rsync 即生效；后端重启 <2s（KeepAlive 拉起）
- NAS 备实例如需同步：rsync src → NAS → `docker-compose build api && up -d`

## 三、双 API 实例与切流

| 实例 | 位置 | 隧道 | 边缘指向 |
| --- | --- | --- | --- |
| **主** | Mac :3002（与 PG15 主库同机） | SSH -R 8802 | `/api/v1/` 当前 |
| 备 | NAS docker :3001 | frp 8801 | 回退时改 upstream |

**切流**：改 `/root/yyc3-leisure-edge/nginx.conf` 的 `proxy_pass` 端口 8802↔8801 → `nginx -s reload`。

## 四、数据库变更（迁移纪律）

- 只加列/加表，不破坏（红线）；迁移文件入 git
- 流程：`migrate deploy`（owner 账号）→ `apply-pg-grants.sql` → 重启 API 实例（Prisma client 结构变更时）
- 已应用迁移台账：
  - `20261102040000_pg_baseline`：PG15 基线（38 表）
  - `20261103000000_ticket_settle_and_booking_hold`（**P1 批次，2026-11-03**）：`room_session.ticket_deduct_amount` + `artist_booking.deposit/hold_minutes/hold_until/call_id`——纯加列,旧代码兼容,可直接回退
- seed：`NODE_ENV=prod` 自动跳过 admin/china/e2epwd 测试账号；seed 含 3 个示例销售经理（未审核，可在档案页软删）

## 五、前端发布注意

- Web 为同源相对路径（`/api/v1`），无内嵌地址
- H5 的 `API_BASE` 为**编译期内联**：`TARO_APP_API_BASE='https://lm.0379.pro/api/v1' pnpm build:h5`——改域名必须重构建
- 小程序（weapp）发布走同一 `API_BASE` 机制 + 微信后台合法域名配置

## 六、回退

- **后端**：`launchctl` 卸载新进程 → `git checkout <旧tag>` → `pnpm build` → KeepAlive 拉起（迁移只加列，旧镜像/旧代码兼容）
- **前端**：ECS 保留上一版目录或 `git` 重建旧 dist 覆盖
- **DB**：主备流复制天然热备；灾难恢复用 `pg_dump` 每日份（NAS V1 池）
