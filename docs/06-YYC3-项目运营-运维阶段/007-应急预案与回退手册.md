## 口径

- **RTO 目标** ≤ 15 分钟（就地切流）；**RPO 目标** ≤ 24 小时（每日 pg_dump + WAL）
- 判级：L1 全站不可用 / L2 功能域不可用 / L3 单点体验

## 一、DB 主库故障（Mac PG15）

1. **判别**：`/api/v1` 全面 5xx/超时；Mac 本机 `pg_isready` 失败
2. **临时**：边缘 upstream 切 NAS 链路——`/root/yyc3-leisure-edge/nginx.conf` 改 8802→8801，reload。备库**只读**：查询可看，写入报错（前台关闭收银/开房等写入口，公告只读）
3. **恢复**：拉起/修复 Mac PG → 主库回归 → upstream 切回 8802
4. **灾难**（主库数据损毁）：以 NAS 备库 `pg_promote()` 提升为新主（注意旧主 fqdn 切换），恢复后重建反向复制；RPO=最后接收的 WAL

## 二、API 实例故障

| 场景 | 处置 |
| --- | --- |
| Mac :3002 崩溃/挂起 | launchd KeepAlive 自动拉起；查 `/tmp/leisure-api-prod.err` |
| Mac 上市电/睡眠 | **Mac 必须防睡眠**（主库机）；临时切 NAS 备实例（8801）+ DB 走 Tailscale 仍可写（主库在 Mac 在线为前提；Mac 离线=全站只读降级） |
| 版本发布后异常 | §回退：launchctl 卸载→旧 dist 重建→拉起；或边缘切 8801（NAS 旧版实例） |

## 三、隧道/边缘故障

| 场景 | 处置 |
| --- | --- |
| SSH 隧道(8802)断 | launchd KeepAlive 自动重连；连续失败查 `yyc3-33` sshd 与 Mac 网络 |
| frp(8801)断 | NAS `docker restart yyc3-leisure-frpc` |
| Traefik/边缘 nginx 异常 | ECS 上重启对应容器；**回退**：临时直连 `http://<NAS>:3001`（仅内网/Tailscale 使用，不走公网） |
| 域名/证书 | LE 90 天自动续；失败时 Traefik 日志 `/root/0379-world/certs`；手动 `certbot renew` |

## 四、数据事故

- **误删业务数据**：主库即真相，先 `pg_dump` 快照当前态 → 从每日备份/WAL 恢复到临时库 → 精准回灌（禁止整库回滚覆盖线上）
- **账务差异**：以 `audit_log` + `stage_fee_txn` 为准账；更正走 REVERSE 反向流水，**禁止 UPDATE/DELETE**（DB 层已收权）
- **勒索/入侵嫌疑**：立即断 ECS 80/443 与 frp → 保留日志 → 走安全事件流程（07 合规域）

## 五、回退速查卡

```
# 后端版本回退(Mac)
cd services/leisure-api && git checkout <旧tag> && pnpm build
kill $(launchctl list | grep leisure-api-prod | awk '{print $1}')   # KeepAlive 拉起
# 切回 NAS 备实例
# ECS: /root/yyc3-leisure-edge/nginx.conf  proxy_pass 8802→8801 ; nginx -s reload
# DB 只读降级
# ECS: upstream 指向 NAS(8801) + 公告只读
```
