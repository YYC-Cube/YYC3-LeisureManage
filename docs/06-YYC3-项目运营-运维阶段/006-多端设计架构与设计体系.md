## 一、四端总览

| 端 | 工程 | 技术栈 | 入口/部署 | 设计基线 |
| --- | --- | --- | --- | --- |
| **Web 管理端** | apps/app-leisure-web | React19+Vite8+Tailwind4(css-first)+@yyc3/ui(源码直出)+hash router | 边缘静态 + 同源 `/api/v1` | 桌面优先,断点 768 自适应,PWA 完整(SW 离线壳) |
| **销售端 H5** | apps/app-mp-artist | Taro4+React(webpack5) | 边缘 `/m/`(API_BASE 编译期内联) | 移动优先,3 Tab(首页/签到/我的)+子页 |
| **销售端小程序** | 同工程 build:weapp | Taro4 | 微信发布(合法域名+凭据) | 同 H5 代码 |
| **API** | services/leisure-api | NestJS10+Prisma5+PG15+Redis | :3002(Mac 主)/:3001(NAS 备) | REST 信封 `{code,msg,data}` |

**共享单源** `packages/leisure-core`：营业日/计费引擎/轮台校验/台票/错误码(19 键)/API Client——**任何端禁止复制实现**。

## 二、--lm-* 设计 token 体系（30 变量，单一事实源 `styles/tokens.css` + `tokens.ts` 镜像）

| 组 | 变量 |
| --- | --- |
| 核心语义 | --lm-bg `#060e1f` · --lm-fg `#e0f0ff` · --lm-primary `#00d4ff` · --lm-primary-fg · --lm-secondary · --lm-muted · --lm-muted-fg `#6bb8d9` · --lm-accent · --lm-danger `#ff3366` · --lm-border · --lm-ring |
| 面板层级 | --lm-card `rgba(10,30,60,.7)` · --lm-panel `rgba(6,14,31,.7)` · --lm-line `rgba(0,212,255,.12)` |
| 功能色 | --lm-success `#00ff88` · --lm-warning `#ffaa00` · --lm-text-muted `#8b9bb4` |
| 图表 | --lm-chart-1~5（青/绿/橙/紫/黄） |
| 字体 | --lm-font-display(Orbitron 栈)· body(Rajdhani 栈,全局生效)· mono(JetBrains Mono 栈) |
| 形状/光效 | --lm-radius(0.75rem,滑杆可调) · --lm-glow-sm/md/lg(随主色派生) |

**规则**：
1. 页面**禁止新增硬编码色**；一律 `text-primary`/`border-line` 等工具类或 `var(--lm-*)`
2. 主题页（设置→主题定制）编辑变量 → localStorage `leisure-theme-v1` → `applier.ensureThemeApplied()` 启动应用；切换带 350ms 过渡
3. 主题可**导出/导入 JSON**（仅 --lm- 前缀键）；跨端共用=导出文件互导
4. 房态色为独立语义（绿空房/红消费/橙预定/蓝清扫/灰维修），**不随主题变**（行业认知优先）

## 三、品牌 logo 全端链路

源：`public/yyc3-icons/`（全平台 AppIcon 集）→ 扁平布局 `macOS/16~512.png` + `Web App/android-chrome-192/512.png` + `favicon-16/32` + `apple-touch-180`
→ 消费：favicon/manifest(PNG 192·512·maskable) / 侧栏品牌头 / AI 浮窗按钮与面板头 / 主题预览身份卡 / H5 首页与我的页 / 小程序模板 data-URI favicon
组件：`components/ai-assistant/YYC3LogoSvg.tsx`（按 size 拾取 16→512）

## 四、交互规范

| 项 | 规范 |
| --- | --- |
| 破坏性操作 | 一律 `ConfirmButton` 二次确认，文案具体化（禁「确定」） |
| 表格 | DataTable 统一（分页/空态/loading/行 hover） |
| Tab/分段 | @yyc3/ui Tabs（分段控件样式,选中青描边）；深链用 `?tab=` |
| 弹窗 | Radix Dialog；表单禁双击（busy 态） |
| 资金写操作 | 幂等键（`idemKey()`）必带 |
| AI 浮窗 | 按钮与面板均可拖拽（位置持久化）；面板右下角缩放（360×460 起）；⌘J 开关；移动端全屏 |
| 空态 | `EmptyState`（图标+标题+描述+行动点） |
| 统计 | `StatCard`（大数字+tone 色点+hint） |

## 五、自适应与断点

- 768px 分界：`useIsMobile()` → 侧栏隐藏+BottomNav；AI 面板全屏
- 触控目标 ≥28px；弹层 shadow `0 10px 50px rgba(0,0,0,.5)`
- H5：Taro postcss 750 设计稿；`static/` 承载 favicon 等免打包资源

## 六、演进基线

新页面/新组件验收清单：token 合规 → 深色对比度 → 触控尺寸 → 空态/加载/错误三态 → 移动端 375px 与 1440px 双检。
