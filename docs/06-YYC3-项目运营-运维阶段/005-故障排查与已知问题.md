## 一、链路与性能

| 症状 | 根因 | 处置 |
| --- | --- | --- |
| **页面整体卡顿**（查询秒级） | Mac↔NAS Tailscale 走 DERP 中继（`relay "nue"`），API↔DB 每查 200ms+ 绕德国 | ✅ 已根治：生产 API 迁 Mac 与主库同机（launchd :3002）；验证 `Tailscale status` 应避免 relay；若复发检查两端 UDP/网络变更 |
| 某查询偶发 1-2s | 命中 DERP 时段或主库磁盘抖动 | 观察 `pg_stat_activity`；必要时切回 NAS 备实例（边缘 upstream 8801） |
| **公网 API 404 新路由/行为像旧版本**(2026-11-03 实录) | 边缘 `nginx.conf` 为**单文件 bind mount**(inode 固定):宿主改配置产生新 inode,容器仍挂旧内容(指向 8801 NAS 旧镜像) | `cd /root/yyc3-leisure-edge && docker compose restart edge`(重启重挂);改 nginx.conf 后**必须 restart 容器**而非仅 reload |
| **边缘容器到 8802 不通(502)** | Mac 隧道 `ssh -R 127.0.0.1:8802` 只绑 ECS 环回(sshd GatewayPorts=no),容器网络命名空间不可达 | ✅ 已建 systemd `yyc3-leisure-8802-relay`(socat 172.17.0.1:8802→环回 8802,仅 docker 网桥可达不暴露公网);`systemctl status yyc3-leisure-8802-relay` 巡检 |
| 静态资源 404 | 边缘 nginx root 配置变动 / rsync 漏文件 | 重新 `rsync dist/ web/`；对照 007 号回退 |
| `sw.js` 404 或被缓存 | 边缘 nginx 缺 `location = /sw.js`(no-cache+root) 专属块 | 已配置；改动后 `docker exec yyc3-leisure-edge nginx -s reload` |

## 二、认证与账号

| 症状 | 根因 | 处置 |
| --- | --- | --- |
| 登录后所有接口 40302「首次登录须先修改默认密码」 | 账号仍用默认口令（机制如此） | 顶栏头像 → 个人信息 → 修改密码；或管理员重置 |
| 连续错 5 次锁 15 分钟（42901） | 防爆破 | 等 15 分钟或 DB 置 `failed_login_count=0,locked_until=null` |
| H5/小程序 401 | token 2h 过期 | 重新进入登录 |
| 忘记管理员密码 | — | DB 重置：`bcrypt` 新哈希写 `admin_user.password_hash` + `must_change_password=true`（ops 执行） |

## 三、业务错误码速查

| 码 | 含义 | 常见场景 |
| --- | --- | --- |
| 40301/40302 | 缺功能码 / 首登未改密 | 补权限或先改密 |
| 40901 腰牌重复 · 40903 规则当日禁改 · 40904 上台超限 · 40905 签退过早 · 40906 有流水禁删 · 40907 房号重复 · 40908/40909 房/人不在 · 40910 点单超限 · 40911 台票余额不足 · 40912 台票过期 · 40913 预约终态 · 40914 轮台越序 | 业务校验 | 按语义处置；全表见 leisure-core errors.ts |
| 41201→HTTP 202 | 手动扣费转审批 | 等待审批人（≠申请人）处理 |
| 42901 | 登录限流 | 15 分钟后重试 |

## 四、前端/PWA

| 症状 | 根因 | 处置 |
| --- | --- | --- |
| 新版本不生效 | SW 缓存壳 | 等 toast 自动刷新，或 DevTools→Application→SW→Unregister+更新 |
| 断网后数据不新 | SWR 秒回缓存 | 恢复联网后刷新；写操作离线必失败（资金红线，设计如此） |
| H5 图标/接口地址不对 | API_BASE 编译期内联 | 用 `TARO_APP_API_BASE=… pnpm build:h5` 重构建发布 |
| 主题改了没全端生效 | 主题存 localStorage(按端) | 导出 JSON → 其他端「导入」→保存 |

## 五、开发/构建已知坑（台账）

| 坑 | 处置 |
| --- | --- |
| Prisma groupBy 放 `$transaction([...])` 元组丢类型 | 改 `Promise.all` 直调 |
| API dev 首跑 tsc 失败→`node --watch` 不启动 | pkill 后重启 `pnpm dev` |
| `tsc` 校验用 `tsconfig.build.json` | 与运行构建同参 |
| Tailwind4 `@theme` 须在编译链内 | tokens.css 经 styles/index.css 导入（勿只挂 main.tsx） |
| Radix Select Item value 禁空串 | 用 'ALL' 哨兵 |
| e2e 改全局 store_config 须自含 set/reset | 多文件并行防串扰 |
| Taro copy schema 校验拒外部文件 | favicon 用 data URI 内嵌 |
| `prisma migrate dev` 非交互拒绝 | `migrate diff --script` 手写迁移 + `deploy` |
| webpackbar×webpack≥5.10 崩 | config/index.ts `plugin.init` 垫片（已内置） |
