## 一、文件体系与流转

| 位置 | 内容 | 权限 |
| --- | --- | --- |
| `~/.yyc3-keybackup/leisure-prod.env`（Mac 本机） | **真值唯一来源**（生成器产物，28 键） | 600 / 目录 700 |
| NAS `/Volume3/docker/yyc3-leisure-api/.env.production` | 部署副本（scp） | 600 |
| 代码仓 `deploy/nas/.env.production.example` | 占位样例（入 git，零真值） | — |

**生成**：`bash services/leisure-api/scripts/gen-prod-secrets.sh [--db-host 100.87.159.21] [--origins "…"]`（openssl 强随机；`--force` 轮换自动留 .bak）
**校验**：`NODE_ENV=prod` 启动硬化——JWT/SCENE 密钥 <32 位或含 `dev-only|change-me|CHANGE_ME|example`、`DATABASE_URL` 含开发口令、`CORS_ORIGINS` 缺失 → **拒绝启动**

## 二、全量变量表（28 键）

### 身份与环境

| 变量 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `NODE_ENV` | ✅ | — | 固定 `prod`；触发硬化校验 |
| `PORT` | ✅ | 3001 | 容器/进程监听端口（Mac 实例=3002） |

### 数据库（PG15 主库 5433；NAS 备库只读）

| 变量 | 说明 |
| --- | --- |
| `DATABASE_URL` | API 运行账号 `leisure_app`（对 stage_fee_txn/ticket_txn/audit_log 无 UPDATE·DELETE）；主机走 **Tailscale 100.87.159.21**（LAN IP 漂移勿用） |
| `DATABASE_URL_OWNER` | 所有者 `leisure`；**仅迁移/seed 手工使用，不进 API 进程** |
| `LEISURE_DB_OWNER_PASSWORD` / `LEISURE_DB_APP_PASSWORD` | 两角色口令原文（bootstrap 脚本消费；32 位无符号） |

### 认证与签名

| 变量 | 说明 |
| --- | --- |
| `JWT_SECRET` / `JWT_REFRESH_SECRET` | 64 字符 base64 随机；access 2h / refresh 7d；轮换=全员重登 |
| `JWT_ACCESS_TTL` / `JWT_REFRESH_TTL` | 缺省 2h / 7d |
| `SCENE_HMAC_KEY` | 报备现场屏二维码 scene 签名（HMAC-SHA256） |

### 网关与前端联动的安全项

| 变量 | 说明 |
| --- | --- |
| `CORS_ORIGINS` | `https://lm.0379.pro,https://lm.0379.world`（prod 必填，与网关域名严格一致） |
| `SWAGGER_ENABLED` | `false`（生产默认关；排障临时开，办完即关） |

### 业务规则（门店级「艺人设置」可覆盖）

| 变量 | 缺省 | 说明 |
| --- | --- | --- |
| `BUSINESS_DAY_CUT` | 08:00 | 营业日切 |
| `TRANSFER_MODE` | manual | — |
| `MANUAL_DEDUCT_THRESHOLD` | 500 | 手动扣费审批阈值(元) |
| `ALLOW_NEGATIVE_BALANCE` | true | 台费负余额允许 |
| `ALLOW_STAGE_WITHOUT_CHECKIN` | false | 未签到上钟(艺人设置⑤可覆盖) |
| `CHECKOUT_MIN_MINUTES` | 60 | 签退时限(40905) |
| `BILL_ROUNDING_MINUTES` | 15 | 计费进位阈值(艺人设置⑦可覆盖) |
| `SELF_ORDER_PER_TXN_LIMIT` / `SELF_ORDER_DAILY_LIMIT` | 500/2000 | 自点单限额(40910) |
| `OPENAPI_ENABLED` | false | 开放 API 预留 |

### 硬件与微信

| 变量 | 说明 |
| --- | --- |
| `VOICE_BOX_URL` | 盒子私网地址模板 `http://<IP>/tts?text={text}`；留空=仅大屏 Web Speech |
| `VOICE_BOX_TIMEOUT_MS` | 3000 |
| `WX_APPID` / `WX_SECRET` | 小程序正式凭据；未填=wx 登录 dev 骨架（生产必须填） |

### 部署侧注入（非 env 文件）

| 项 | 说明 |
| --- | --- |
| `REDIS_URL` | compose 注入 `redis://redis:6379` |
| `NODE_ENV`/`PORT` | Mac launchd 注入 prod/3002 |

## 三、轮换手册

| 对象 | 操作 | 影响 |
| --- | --- | --- |
| JWT 双密钥 | 改 keybackup 文件 → 重启 API 实例 | 全员重登 |
| SCENE_HMAC_KEY | 同上 | 现场屏旧码 60s 内失效 |
| DB app 口令 | keybackup 改 → `ALTER ROLE leisure_app`（psql 变量法）→ 重启 API | 连接重连 |
| DB owner 口令 | 同上（ALTER ROLE leisure） | 仅迁移流程 |
| 轮换留痕 | 生成器自动 `.bak-<时间戳>`(600) | — |
