## 二·B Owner 设计理念裁决(2026-11-04,下一批规划纲)
1. **对齐优先**:先补与我们已有功能有衔接的模块;无关模块收进「功能定制」收集回馈
2. **功能定制回馈模块**:无关模块做成定制申请(点击定制→提交→Owner 收回馈消息,可附截图沟通)→最后拟定排期——**产品需求收集通道**
3. **移动端设计理念(核心)**:财务数据及不影响移动端工作的 → **放 web 端**;移动端=**前端可视化图表+模块显示,不出示具体详情数据**——精致化+视觉化(图表卡片,不拉明细表)
4. **沟通功能申请(Owner)**:群聊/组沟通功能进移动端(IM 最小闭环)
5. **授权统筹**:底层数据及路由由我方统筹设计搭建;数据保通、全局一致;竞品图示仅为表达替补,由我方取开源组件/代码库实现理念设计
