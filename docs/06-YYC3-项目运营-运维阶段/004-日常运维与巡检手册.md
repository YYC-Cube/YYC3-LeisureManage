## 一、每日（约 5 分钟）

1. **双轨对账录数**：管理端「报表 → 双轨对账」→ 选昨日 → 录入智慧商家对侧 4 数（开房数/时间费/点单额/签到人数）→ 看是否 MATCHED；顶部 14 格门禁面板盯 `streak`
2. **抽查日切**：日志应出现 `daily summary materialized` 与 `recon self snapshot`（Mac: `/tmp/leisure-api-prod.log`）
3. **备份确认**：`pg_dump` 每日份已落 NAS V1 池（脚本化后为自动，需人工抽查文件时间戳）
4. **边缘健康**：`https://lm.0379.world/api/v1/auth/me` = 401；NAS `docker ps` 两容器 healthy

## 二、每周

- `pg_dump` 全量 + WAL 归档保留 ≥7 天核对
- 审计表抽查：`audit_log` 无异常批量操作；`stage_fee_txn` 与日切汇总平衡（balanced=true）
- 主题/密钥：无轮换需求则不动；有轮换按 002 号 §三

## 三、后台常驻组件（Mac launchd）

| Label | 作用 | 日志 |
| --- | --- | --- |
| `com.yyc3.leisure-api-prod` | 生产 API :3002(KeepAlive 崩溃拉起) | `/tmp/leisure-api-prod.log(.err)` |
| `com.yyc3.leisure-frp` | SSH 反向隧道 8802→3002(断线自愈) | `/tmp/leisure-frp.log(.err)` |

操作：`launchctl list | grep leisure`；重载：`launchctl unload/load ~/Library/LaunchAgents/<plist>`。

## 四、日切 job（进程内自动）

- 60s 轮询幂等执行：物化上一完整营业日 `daily_summary` → 明细和=汇总校验 → `job_run_log` 留痕 → 对账自算快照（PENDING_LEGACY）
- 巡检点：`job_run_log` 无 FAILED；`recon_diff` 昨日四行 status=PENDING_LEGACY（待录对侧）

## 五、已知节奏性事项

- **后到数据打回 OPEN**：对侧录入后又发生补钟/补结算 → 该日自动回 OPEN（真值维护），重导修正值即可
- **台票过期展示**：过期票余额视图已归零；日切写 EXPIRE 负数行为 P2 增强
- **主题页**：调色即时全站生效；「保存」仅本浏览器持久化（多端共用主题=导出 JSON → 其他端导入）

## 六、巡检清单（每周打勾）

- [ ] edge nginx 配置 diff（dynamic.yml 是否被其他会话改动）
- [ ] NAS API 备实例可一键拉起（compose up 验证）
- [ ] 密钥文件权限 600/700 抽查
- [ ] PG 流复制状态 `pg_stat_replication` = streaming
- [ ] SW 版本：线上 `sw.js` Cache-Control=no-cache 且内容与 dist 一致
- [ ] 磁盘：NAS V1(备份池)/V3(Docker) 使用率；Mac 主库盘
