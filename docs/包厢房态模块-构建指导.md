# 包厢房态模块 · 构建指导

> 版本:v1.0(2026-11-01)|上游依据:《需求全集 V3.0》第五章(房号管理)/第六章(进位计费)· leisure-core 已实现原语
> 模块定位:**实测系统「包厢状态」看板的简化重构**——只做 开房 / 关房 两个动作,去掉实测系统的多模式复杂选项
> 配套文档:《包厢操作与艺人自点单-构建指导》(点单)·《艺人模块融合与数据互通-设计指导》(融合与互通)

## 一、与实测系统的裁剪对照(为什么做减法)

| 实测系统(智慧商家 App 包厢状态页,2026-11-01 截图取证) | 本模块裁决 | 理由 |
|---|---|---|
| 开房多模式:计时/包断/低消/套餐/团购 | **仅保留「小时计费」单模式**(第六章规则,`calcBillHours` 已在 leisure-core) | 独立系统起步;FLAT 模式已在 leisure-core 预留,II 期可回补 |
| 房内操作 25 键(结账买单/收款/预买/转房/续时/锁房/暂停营业/退款退货/商品免单/商品赠送/商品转赠送/挂账/兑换/删歌/远程点歌/送花…) | **收敛为 4 个动作:开房 · 关房(结算) · 清扫完成 · 维修标记** | 用户裁决「不需要复杂选项」;其余动作归入关房结算单或 II 期 |
| 徽标 12 种(满低消/会员/转房/续房/预订/续时/结账/待客/预买/包断/暂停营业/服务) | **无徽标**(无低消/预订等概念);保留「超时提醒」单徽标(可选,II 期) | 规则简化 |
| 统计行:满低消/会员/服务/转房/续房/预订/续时/结账/待客/预买/包断/暂停营业 | **仅四色统计:总数/空闲/消费中/维修中/清扫中** | 对齐截图主行 |
| 快捷键:暂停营业/恢复营业/一键清扫完成/一键开房 | **保留一键清扫完成 + 一键开房(自动绑定当日已签到艺人)**;暂停/恢复营业为店级开关(可配,默认隐藏) | 房务核心 |
| 信息行:天气/当日订单/当日未收款/当日收益 | 保留:当日开房数/当日收益/当前未收款(口径=房账未结) | 经营必需 |

**保留不裁的实测资产**:31 包厢色卡网格布局、房名/日总收益/消费时长卡片三要素、四色语义(空闲绿/消费中红/清扫蓝/维修灰)、营业日 08:00 日切。

## 二、房态状态机(与第五章「占用自动翻转」对齐)

```
                    开房(创建房账 session)
        ┌──────────────────────────────────────┐
        │                                      ▼
   [ 空闲 IDLE ]                          [ 消费中 OPEN ]
        ▲                                      │ 关房(结算单支付完成)
        │        清扫完成(一键/单房)             ▼
        └──────────────────────────────── [ 清扫中 CLEANING ]

   [ 维修中 MAINTENANCE ]:任意非 OPEN 态可标记进入;恢复 → 空闲
   [ 停用 ]:档案级(第五章 5.2 启用/停用),停用房不可开房
```

- **消费中 = 派生态**:存在未关房的 `room_session` 即消费中(对齐需求全集 5.3-3「在钟自动占用」);`room.status` 仅持久化 CLEANING / MAINTENANCE 两个非会话态
- 开房前置校验:房未被占用(40907 房号冲突沿用 leisure-core `ERR.ROOM_NO_DUPLICATED`)、房非维修/停用、(联动)开房发起人须当日已报备签到

## 三、数据模型(增量 DDL;复用 11 号文档已有 room_type / show_session)

```sql
-- 包厢档案(第五章 5.2;房号为门店内唯一业务键)
CREATE TABLE room (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  store_id      BIGINT UNSIGNED NOT NULL,
  room_no       VARCHAR(32)  NOT NULL COMMENT '房号(实测:A01/VIP03/8311),门店唯一',
  name          VARCHAR(64)  NULL COMMENT '包厢名称',
  room_type_id  BIGINT UNSIGNED NULL COMMENT '包厢类型(联动 room_type 字典)',
  capacity      INT          NULL COMMENT '容纳人数',
  hourly_rate   DECIMAL(10,2) NOT NULL DEFAULT 0 COMMENT '房计时单价(元/小时,房型级可覆盖)',
  status        VARCHAR(16)  NOT NULL DEFAULT 'IDLE' COMMENT 'IDLE/OPEN(派生)/CLEANING/MAINTENANCE/DISABLED',
  remark        VARCHAR(255) NULL,
  deleted_at    DATETIME NULL,
  UNIQUE KEY uk_store_roomno (store_id, room_no),
  KEY idx_store_status (store_id, status)
) COMMENT '包厢档案';

-- 房账(开房单;房维度事实源;艺人维度上下钟仍走 show_session,双向关联)
CREATE TABLE room_session (
  id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  store_id        BIGINT UNSIGNED NOT NULL,
  business_date   DATE NOT NULL,
  room_id         BIGINT UNSIGNED NOT NULL,
  room_no         VARCHAR(32) NOT NULL,
  opened_by       BIGINT UNSIGNED NOT NULL COMMENT '开房发起人(艺人/管理员)',
  artist_ids      JSON NOT NULL COMMENT '在场艺人数组(可空=纯房账;艺人进出走 room_session_artist)',
  start_at        DATETIME NOT NULL,
  end_at          DATETIME NULL,
  duration_minutes INT NULL,
  -- 计费快照(开房时固化,后改配置不影响本单;对齐 leisure-core RoomBillingConfig)
  unit_price      DECIMAL(10,2) NOT NULL DEFAULT 0 COMMENT '时薪快照',
  rounding_enabled TINYINT(1) NOT NULL DEFAULT 1,
  rounding_threshold_minutes INT NOT NULL DEFAULT 15,
  bill_hours      INT NULL COMMENT '计费小时(calcBillHours 核算)',
  room_fee        DECIMAL(10,2) NULL COMMENT '时间费',
  order_total     DECIMAL(10,2) NOT NULL DEFAULT 0 COMMENT 'Σ自点单金额(冗余,点单时累加)',
  total_amount    DECIMAL(10,2) NULL COMMENT '结算总额=room_fee+order_total(±台费抵扣)',
  settle_type     VARCHAR(16) NULL COMMENT '结算方式:CASH/FEE_DEDUCT/MIXED',
  fee_deduct_amount DECIMAL(10,2) NULL COMMENT '台费抵扣额',
  status          VARCHAR(16) NOT NULL DEFAULT 'OPEN' COMMENT 'OPEN/CLOSED',
  closed_by       BIGINT UNSIGNED NULL,
  remark          VARCHAR(255) NULL,
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  closed_at       DATETIME NULL,
  UNIQUE KEY uk_room_open (room_id, status) /* 生成列(status='OPEN' 时 room_id 唯一)或应用层锁兜底 */,
  KEY idx_store_date (store_id, business_date),
  KEY idx_room (room_id, start_at)
) COMMENT '房账(开房单;只增,关房为更新终态字段)';

-- 房内艺人进出流水(支持中途进出,替代实测「串台」复杂度)
CREATE TABLE room_session_artist (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  session_id    BIGINT UNSIGNED NOT NULL,
  artist_id     BIGINT UNSIGNED NOT NULL,
  joined_at     DATETIME NOT NULL,
  left_at       DATETIME NULL,
  UNIQUE KEY uk_live (session_id, artist_id, left_at),
  KEY idx_artist (artist_id, joined_at)
) COMMENT '房内艺人进出(点单权限依据)';
```

> **leisure-core 增补清单**(实现时同步):`RoomSession` / `SelfOrder` 类型、`RoomStatus` 枚举、`FeeTxnType` 增 `ROOM_SETTLE`(房账结算台费抵扣)、`ERR.ROOM_NOT_OPEN(40908)` / `ERR.NOT_IN_ROOM(40909)` / `ERR.ORDER_LIMIT_EXCEEDED(40910)`(建议值,以 ERR 单源为准)。时间费计算**复用已实现** `calcBillHours(actualMinutes, BillRoundingConfig)`(第六章算法,进位阈值快照语义一致)。

## 四、API 增补(对齐 04 号文档风格;前缀 /api/v1)

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /rooms/board | **看板聚合**(对齐截图):返回 四色统计 + 房卡数组(房名/日总收益/时长/状态/房内艺人);查询参数 area/roomType/keyword |
| POST | /rooms | 新增包厢(房号唯一→40907) |
| PUT | /rooms/{id} | 编辑/停用/启用 |
| POST | /rooms/{id}/maintenance | 维修标记 / 恢复 |
| POST | /room-sessions/open | **开房**:{roomId, artistIds[]};事务:唯一 OPEN 校验→建 room_session→房间态 OPEN→发 ROOM_OPENED 事件 |
| POST | /room-sessions/{id}/close | **关房结算**:核算 bill_hours×unit_price(开房快照)→ 汇总 order_total → 台费抵扣(可选,落 ROOM_SETTLE 流水)→ 支付登记 → CLOSED → 房态 CLEANING;二次确认 |
| POST | /rooms/{id}/cleaning-done | 清扫完成 → 空闲(单房;一键版另接口) |
| POST | /rooms/bulk-cleaning-done | 一键清扫完成(全部 CLEANING → IDLE) |

## 五、页面(管理端 Web;艺人端见《包厢操作与艺人自点单》)

### 5.1 房态看板(对齐实测截图布局)
- **筛选行**:门店 / 区域(预留) / 包厢类型 / 排序方式
- **统计行**:总数 · 空闲 N · 消费中 N · 维修中 N · 清扫中 N(色点)
- **信息行**:当日开房数 · 当日收益 · 当前未收款(房账 OPEN 的 Σ预估)
- **快捷键**:一键清扫完成 · 一键开房(可选:暂停/恢复营业,`SHOW_STORE_TOGGLE=false` 默认隐藏)
- **色卡网格**:房名+房型 / 日总收益 / 开房次数或消费时长 / 状态文案;色:空闲绿·消费中红·清扫蓝·维修灰;点击色卡 → 房详情抽屉(房账明细/房内艺人/操作按钮)
- 刷新:10s 轮询(阶段1)→ WebSocket(II 期)

### 5.2 开房弹窗
- 选房(空闲房列表,房号搜索;占用/维修/停用禁选)→ 在场艺人多选(默认勾选当日已签到艺人)→ 确认
- 展示:时薪快照、进位规则提示(「超 N 分钟进 1 小时」)

### 5.3 关房结算单
- 明细:时间费(实际时长→计费小时→金额,**开房快照**)· 点单明细(逐单展开)· 合计
- 台费抵扣:勾选在场艺人 → 各自余额校验 → 抵扣额分配(手动填)→ 生成 ROOM_SETTLE 流水
- 支付:现金 / 台费抵扣 / 混合;**二次确认**(对齐实测红线交互);完成 → 打印/导出结算单

### 5.4 清扫与维修
- 清扫队列(CLEANING 列表 + 一键完成);维修标记(原因必填)与恢复

## 六、验收要点(并入 08 号文档用例)

| # | 用例 | 预期 |
|---|---|---|
| R-01★ | 开房 | session OPEN + 房态消费中 + 事件 ROOM_OPENED;同房重复开房被唯一约束拦截 |
| R-02 | 关房计费快照 | 开房后改进位阈值/时薪,关房仍按快照核算 |
| R-03 | 进位边界 | 75 分钟(N=15)→2 小时;76 分钟→3 小时(对齐第六章对照表) |
| R-04 | 跨天连续 | 08:00 班次周期跨天不截断(crossDayAccumulate) |
| R-05★ | 关房结算 | 时间费+Σ点单=总额;台费抵扣生成 ROOM_SETTLE 流水且余额扣减一致 |
| R-06 | 清扫流转 | 关房→CLEANING→清扫完成→IDLE;一键完成全量生效 |
| R-07 | 维修旁路 | 维修房开房被拒;恢复后可开 |
| R-08 | 权限 | 关房仅开房人/管理员;结算需二次确认 |
