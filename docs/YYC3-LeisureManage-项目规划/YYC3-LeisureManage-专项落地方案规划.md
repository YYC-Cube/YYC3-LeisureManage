## 二、工作通告编辑增强(本批实施)

### 2.1 数据模型(notice 表加列,迁移 20261104110000_notice_play)

| 列 | 类型 | 语义 |
|---|---|---|
| play_times | INT 默认 3 | 公告条滚动播放次数(0=常驻循环;工作台播 N 次后隐藏该条) |
| play_start / play_end | DATETIME? | 展示时段窗口(空=立即+永久;窗口外自动不显示) |
| play_speed | INT 默认 22 | 公告条单轮滚动时长(秒;10 慢 / 22 中 / 40 快→慢速) |
| visible_titles | VARCHAR(255)? | 可看职级白名单(逗号分隔 VP/MANAGER_DIRECTOR/MANAGER/CASHIER/FINANCE;空=全员) |
| remind | BOOL 默认 true | 提醒效果:新通告(24h 内)工作台红点+首次进入自动弹层一次(localStorage 记已读 id) |

### 2.2 API

- `POST /notices`(扩展字段全量)/ **`PUT /notices/:id`(新增编辑,含下线=直接改时段)**
- `GET /notices` 返回全字段;**按调用者职级过滤**:员工 title ∈ visible_titles 或 visible_titles 空;非白名单条目不下发
- 守卫不变:写 setting:manage;读任意登录者

### 2.3 界面

- **管理端工作通告页**:卡片增「编辑」钮(复用发布表单,含新字段:播放次数/起止时间/速度 select/职级多选/提醒开关);列表展示配置摘要
- **移动工作台**:公告条按 speed 渲染、按 play_times 计数隐藏(localStorage 计数)、窗口外不渲染;**新通告(remind=true 且 24h 内且未读)进入自动弹层一次**;通知铃红点=未读通告数
