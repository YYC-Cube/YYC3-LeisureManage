# 06 · 权限与安全设计

> 版本:v1.1(2026-11-01 裁决修订)|**定位裁决:独立运营,完全脱离「智慧商家」**——"收银联动账号"改为本系统收银角色(PWA/管理端登录),不再服务主系统调用
> 版本:v1.0(2026-11-01)

## 1. RBAC 模型(对齐实测权限矩阵交互)

```
admin_user ─n:1─ role ─(perm_codes JSON)─ 功能码集合
艺人端: wechat_openid → artist(仅本人数据,无角色)
```

### 1.1 功能码(与实测 App 权限矩阵同构)

| 域 | 功能码 |
|---|---|
| 档案 | artist:view / artist:edit / artist:delete / artist:transfer / artist:batch |
| 配置 | level:manage / group:manage / feerule:manage / ticketrule:manage |
| 台费 | fee:recharge / fee:manual / fee:ledger:view / fee:ledger:export |
| 台票 | ticket:buy / ticket:use / ticket:ledger:view |
| 考勤 | attend:qrcode / attend:manual / attend:ledger:view / attend:summary:view |
| 场次 | session:view / session:finish(代下钟) / session:cross |
| 展示 | showcase:cast / showcase:view |
| 订单评价 | order:view / review:view |
| 系统 | approval:decide / audit:view / report:export / setting:manage |

### 1.2 预置角色

| 角色 | 功能码(默认) |
|---|---|
| 管理员 | 全部 |
| 艺人主管 | attend:* / session:view,finish / artist:view / report:export(限本组数据范围) |
| 财务 | fee:*(除 manual 审批外)/ ticket:ledger / report:export |
| 收银员 | session:start,finish / ticket:use(Web 管理端/PWA 登录使用;v1.1 裁决:不再服务主系统联动调用) |

### 1.3 数据范围(Data Scope)
- 主管:所有查询强制 `group_id IN (主管组)`;汇总仅本组
- 多店:用户-store 映射;跨店查询拒绝

## 2. 认证与会话

| 端 | 方式 | 有效期 |
|---|---|---|
| 管理端 | 手机号+密码 → JWT(access 2h + refresh 7d);连续错 5 次锁 15 分钟 | 对齐实测"结账员工验证"思路,敏感操作再验密码 |
| 艺人端 | wx.login → session_key;绑定后 openid 换 JWT(30d 滑动) | — |
| 敏感操作再验证 | 手动扣费/转移/代下钟:输入登录密码(对齐实测"密码验证族"设计) | 单次 |

## 3. 资金安全(台费/台票)

1. **流水不可变**:DB 账号对 txn/audit 表 revoke UPDATE/DELETE;更正=REVERSE 反向流水
2. **幂等**:写接口 Idempotency-Key;同 key 24h 去重
3. **双人防线**:手动扣费 ≥阈值 → approval;审批与申请人不得同一人
4. **对账**:日切任务三对——明细和 vs daily_summary;充值流水 vs 渠道账单(抖音);余额 = Σ流水 抽查
5. **展示**:负余额红色高亮(对齐实测未收款红字风格)

## 4. 敏感数据合规(个保法)

| 数据 | 处理 |
|---|---|
| 身份证号 | AES-256-GCM 加密存储(KMS 托管密钥,90 天轮换);展示脱敏(前3后4);解密操作审计 |
| 身份证照/人像照 | OSS 私有桶 + STS 短时签名 URL(≤5 分钟);艺人端主页仅人像且可关 |
| 地理位置 | 仅存签到/签退点位;管理端展示到小区级(逆地理);保留 180 天后模糊化 |
| 手机号 | 展示脱敏;短信经模板报备 |
| 日志 | 审计日志含 before/after 快照;敏感字段落日志前脱敏 |

## 5. 审计

- 覆盖动作:档案 CRUD/转移、规则 CRUD、资金全部、代操作(补打卡/代下钟)、审批、权限变更、导出
- 内容:谁(actor)/何时/何地(IP+UA)/何事(action)/前后值
- 不可改:追加写账号;月度归档哈希链(防篡改校验)

## 6. 接口安全

- 全站 HTTPS(TLS1.2+);小程序强制校验域名
- 限流:签到 1 次/人/分钟;查询 60 req/min;资金写 10 req/min
- WAF:SQLi/XSS 基线;文件上传:类型白名单(jpg/png)+大小 5M+病毒扫描
- 越权防护:所有 `/{id}` 接口校验资源属主(店/组范围);水平越权用例纳入 CI

## 7. 可用与容灾

- 签到离线兜底:小程序本地队列,网络恢复重传(带客户端时间戳,服务端按序去重)
- 备份:每日全量+binlog;RPO≤5min,RTO≤1h;恢复演练季度一次
- 主系统联动故障降级:integration 熔断后,本项目独立运行,事件本地排队补投
