## 一、范围与目标

覆盖 Owner 需求四要素:**所有岗位 · 业绩提成 · 员工奖惩 · 所有金额/费用类目**,支持**金额、比例、支付方式**三类设定。定位:III-B 经营增值批次核心模块(008/009 规划承接);与既有底座衔接——

- **条线/部门/汇报线**:artist.line(SELL/RESOURCE,2026-11-04 已落列)+ department 树 + admin_user.managerId——分账对象与归集维度直接复用
- **资金底座**:关房结算 ROOM_SETTLE 只增、台费流水只增、审批流(双人)、日切营业日——计提与结算沿用同一纪律
- **资源经理线**:资源经理档案(复刻销售经理档案,已上线)自动纳入分账可选部门/分组

## 三、领域模型(草案)

### 3.1 类目(Category,分账触发源)

| 类目(预置,可扩展) | 计提基数来源 | 说明 |
|---|---|---|
| 上钟业绩 | showSession.feeAmount(营业日日切后) | 销售经理/资源经理上钟时长费 |
| 房账消费 | room_session.totalAmount | 关房结算总额按参与人分摊 |
| 自点单 | self_order.totalAmount | 点单提成基数 |
| 台票销售 | ticket_txn type=BUY amount | 台票出售提成 |
| 充值业绩 | stage_fee_txn type=RECHARGE | 充值拉单业绩 |
| 手动调整 | 人工录入 | 奖惩/补贴/罚扣(正负) |

### 3.2 方案与规则

```
SplitPlan(分账方案)
  id/storeId/name(如「销售经理月度提成」)/category(类目)/status(DRAFT·ACTIVE·ARCHIVED)
  periodType(DAILY/WEEKLY/MONTHLY)/effectiveFrom/effectiveTo
SplitRule(规则项,挂在方案下)
  planId/岗位或条线(admin_title 或 artist_line 或 departmentId)
  calcType(PERCENT 比例 / FIXED 固定金额 / TIERED 阶梯)
  percent(比例,0-100×2 位)/fixedAmount/阶梯表 tierJson[{min,max,percent}]
  payMethod(CASH/TRANSFER/BANK/OFFSET 抵扣台费)/payCycle
  rewardType(REWARD 提成奖励 / PENALTY 奖惩扣罚)
SplitEntry(计提记录,只增)
  planId/ruleId/ userId(分账对象)/line/departmentId/ baseAmount(基数)/amount(计提额)
  businessDate/refType+refId(溯源到 session/room_session/txn)/status(ACCRUED→CONFIRMED→PAID)
  payMethod/payRef(支付凭证号)/confirmedBy/paidAt
```

**红线沿用**:SplitEntry 只增不改(冲正=反向条目);全部显式 store_id;计提按营业日快照(规则改不影响已计提);复核走既有 approval(双人)。

### 3.3 闭环

```
方案配置(DRAFT→ACTIVE)
  → 日切 job 追加计提步:按 ACTIVE 方案×类目基数逐规则算额 → SplitEntry(ACCRUED)
  → 周期结算单:按 payCycle 汇总 ACCRUED → 结算单(人/期/金额/支付方式)
  → 复核(审批流,≠制单人)→ CONFIRMED
  → 支付确认(线下发放+凭证号)→ PAID;OFFSET 模式可直连台费冲抵(生成 REVERSE/RECHARGE 流水,维持只增)
  → 对账:计提合计 vs 结算合计 vs 支付合计 三向平衡(日切 job 扩展校验)
```

## 四、API 草案(setting:manage/finance 域)

```
GET/POST/PUT/DELETE /split/plans(/:id)          方案与规则(嵌套)
POST               /split/plans/:id/activate|archive
GET                /split/entries?userId&line&departmentId&businessDateFrom/To&status
POST               /split/entries              手动调整类目计提(奖惩;审批联动)
POST               /split/entries/:id/reverse  冲正(反向条目)
GET/POST           /split/settlements          结算单生成/列表
POST               /split/settlements/:id/confirm|pay
GET                /split/notices/:id/…        (预留)
```

前端:财务域新页 `/split/plans`(方案+规则)、`/split/entries`(计提流水+手动调整)、`/split/settlements`(结算单+支付确认);销售端「我的分成」只读页。
